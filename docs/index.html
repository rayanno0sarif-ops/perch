What it does

Everything you reach for, in one place.

Rest the pointer on the pill and it opens into tabs. Drag it anywhere, lock it, or let it thin out over maximised windows.

Music

Cover, controls, seek and volume for any player, plus synced lyrics.

Clipboard

Search, pin, keep between sessions encrypted, skip anything that looks like a password.

Shelf

Park files between apps, then drag them out again.

Screenshots

Frozen-screen capture, an editor with arrows, blur and backgrounds, pins, and scrolling capture.

Recorder

Record an area with sound and microphone, trim, and save MP4 or GIF.

Window switcher

Alt+Tab with live previews and search. Layouts, thirds, sixths, gaps, Alt-drag to move.

Utilities

Keep awake, colour picker, text and QR from the screen, calculator, dark mode, quit others.

Manage

Uninstall with leftovers, devices, winget, cleaner with a schedule, processes, wallpaper.

Timer & Calendar

Pomodoro, stopwatch, a month view from your calendars and .ics files.

Watch

Pick part of the screen and get told when it changes or shows what you wait for.

AI agents

Token and cost usage of Claude Code and Codex, read from files already on your PC.

Assistant

Chat with Claude using your own key, and have it write extensions you review first.

In control

Off until you switch it on.

The keyboard and mouse hooks are the part of an app like this that deserves suspicion, so they are strict.

  • Nothing is hooked on a fresh install. Hooks start only when a tweak needs them and stop when the last one is off.
  • Games are left alone. The mouse hook steps aside while a full-screen game is in front.
  • One screen tells you whether the mouse or keyboard is being watched right now.
  • Bundles set Perch up in a click: Essentials, Windows, Battery and quiet, Everything.
  • Updates never grow it. New tabs start hidden.
Privacy

Local first. No account, no telemetry.

The network is touched only by things you can see.

Stays on your PC

Settings, clipboard history (encrypted if kept), screenshots, recordings.

Only when you ask

Weather, the speed test, winget, lyrics lookup, the assistant, translation and .ics links.

Read-only agents

Usage comes from session files only: dates, models, projects and token counts, never prompts or replies.

Careful with deletes

Leftovers, cleaner and download cleanup go to the Recycle Bin or ask first.

Get it

Build it yourself.

There is no installer yet. Windows needs the .NET 10 SDK.

Windows

cd Perch
dotnet build -c Release
.\bin\Release\net10.0-windows10.0.19041.0\Perch.exe

macOS untested

cd PerchMac
./build.sh
open Perch.app

The Mac version was written without a Mac or a Swift compiler. It has never been built; expect fixes.
